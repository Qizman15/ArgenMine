# Оплата и баланс через LiqPay (ПриватБанк)
LiqPay — платёжный сервис ПриватБанка. Схема: игрок платит картой на странице LiqPay -> LiqPay вызывает php/liqpay.php ->
сервер проверяет подпись, сумму и валюту -> зачисляет баланс (пополнение) или выдаёт донат через RCON (lp user ... parent add ...).
Покупка с баланса идёт мгновенно, без банка. Деньги за карточные платежи LiqPay перечисляет на счёт вашей компании в LiqPay.

## Что нужно
1. Ключи LiqPay: кабинет liqpay.ua -> ваша компания -> API: Public key и Private key. Тестовые ключи начинаются с `sandbox_`
   (приватный — `sandbox_...`, публичный — `sandbox_i...`). Строка, которую вы присылали, похожа на ПРИВАТНЫЙ ключ; нужен ещё публичный.
2. Для приёма настоящих платежей, как пишет сам сервис, нужно стать клиентом ПриватБанка и создать компанию в LiqPay с адресом вашего сайта; какой статус нужен — уточните у банка.
3. Домен с HTTPS: LiqPay должен достучаться до https://ВАШ_ДОМЕН/php/liqpay.php. Без домена callback не сработает, и деньги не зачислятся.
   Для теста без домена: `cloudflared tunnel --url http://localhost:80`, полученный https-адрес впишите в `site_url`.
4. php/config.php: `liqpay.public`, `liqpay.private`, `sandbox` (true = тест, false = настоящие деньги), `site_url`, `rub_to_uah`, БД, RCON.
   В index.html: `CFG.BACKEND=true`.
5. Cloudflare: добавьте правило WAF «Skip» для пути /php/liqpay.php, иначе защита от ботов может блокировать запросы LiqPay.
6. Ключи храните только в config.php на сервере. Не вставляйте их в index.html и не отправляйте в чаты (если ключ засветился — выпустите новый в кабинете).

## Проверка
Пополните баланс на 10 ₽ в тестовом режиме -> баланс на сайте вырастет. Купите донат с баланса -> статус «Выдан» в админ-панели.
Если RCON недоступен, заказ остаётся «Оплачен», в админ-панели есть кнопка «Выдать».
Курс `rub_to_uah` пересчитывает цены из ₽ в ₴ при оплате картой — задайте реальный.
