# Промт, по которому собран сайт ArgenMine
Ты — full-stack разработчик и дизайнер. Сделай на русском языке сайт «ArgenMine» — донат-магазин Minecraft-сервера с форумом.
Свой стиль: тёмный фон, бирюзово-фиолетовый градиент, скруглённые карточки; светлая тема через prefers-color-scheme.
Страницы (SPA, hash-роутинг): Главная, Магазин, Форум, Пользователи, Команда, Правила, Игры, Друзья, Достижения, Чат, Поиск, Оферта, Вход, Регистрация, Восстановление пароля.
Магазин: 9 донатов с картинками (GRIEFER 19, GHAST 698, KRAKEN 629, WITHER 649, DRAGON 779, STINGER 1024, ETERNITY 1788, DEMON 2430, D. ADMIN 5349 руб.).
Карточка открывается окном: категория, название, цена, «Добавить в корзину», списки КОМАНДЫ и БОНУСЫ. Команда выдачи: `lp user %username% parent add <группа>`, снятия: `... remove <группа>`.
Выбор валюты: RUB, UAH, BYN, KZT, GEL, USD, EUR (курсы настраиваемые). Корзина.
Оформление заказа в 3 шага: (1) «Покупка товара» — ник, e-mail, промокод, галочки «принимаю оферту» и «карта принадлежит мне», кнопка «Продолжить»;
(1а) если игрок никогда не заходил на сервер — окно «Игрок X никогда не заходил на сервер «Выживание». Услуга может быть не предоставлена!» с кнопкой «Изменить никнейм»;
(2) «Выберите метод оплаты»: СБП, Российские карты, Весь мир (Visa/Mastercard/Apple/Google Pay), Зарубежная оплата (только Mastercard), Криптовалюта, CryptoBot; кнопка «Оплатить N ₽».
Блок «Последние покупки» — бегущая лента карточек (картинка, [ товар 1 шт. ], ник со звёздочками). Блок «Наши серверы»: «Сейчас играют N», кнопка с IP, «N игроков из M».
Админ-панель (только создатель и главный администратор): обзор (пользователи, заказы, выручка), заказы со сменой статуса и повторной выдачей, товары (цена, в продаже), пользователи (роли, удаление), промокоды, модерация форума и чата.
Команда проекта: Создатель — Qizman, Главный администратор — FOGR, больше никого.
Регистрация с e-mail; «Забыли пароль?» — письмо со ссылкой (токен хранится хешем, живёт 1 час, ответ одинаковый для любого e-mail).
Форум (разделы с темами), общий чат, друзья, достижения, мини-игры (Змейка, Память, Кликер), оферта-шаблон.
Бэкенд: PHP 8 + MySQL (prepared statements, password_hash), выдача после оплаты через RCON, вебхук с проверкой подписи, Cloudflare Turnstile на формах входа.
Выдай: index.html, php/api.php, php/webhook.php, sql для MySQL Workbench, nginx.conf, инструкции Cloudflare и деплоя на VPS. Без лишних функций.
Дополнение: главная как у FoxDon (шапка с меню и «Сейчас играют», баннер, вкладки серверов и категорий, карточки с кнопкой «Приобрести»).
Баланс на сайте: пополнение через LiqPay (ПриватБанк), оплата донатов с баланса. Промокоды: QIZMAN −10%, ROKETGARI −5% на все товары. Покупка картой — через LiqPay в гривнах.
